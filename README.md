Delphix, now part of Perforce Software, is a DevOps data platform for test data management, data virtualization, and data compliance. Its core products are Continuous Data (fast, space-efficient virtual database provisioning, refresh, bookmarking, and time-travel across Oracle, SQL Server, SAP ASE, PostgreSQL, and AppData sources) and Continuous Compliance (automated data masking and synthetic data generation to protect sensitive information in non-production environments). Delphix is API-first: every function is available through the Data Control Tower (DCT) REST API, the dct-toolkit CLI, the delphixpy Python bindings, and an official Model Context Protocol (MCP) server, so teams can embed compliant data delivery into CI/CD, DevOps, and AI model-training pipelines.

**Areas:** Company · Data Management · Test Data Management · Data Virtualization · Data Masking · Data Compliance · Database · DevOps · Synthetic Data · Data Control Tower

## How this profile is made
